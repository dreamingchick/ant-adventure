# 개미의 모험 · 챕터 2 · 부엌으로 가는 길

거실 결과 화면이나 챕터 1을 클리어한 타이틀에서 진입한다. 새 저장은 거실부터 시작한다. 기존 stage2.html 주소는 같은 사이트의 통합 화면으로 이동한다.

| 구간 | 주요 조작 |
| --- | --- |
| 거실 문턱 | 두 높이의 턱에서 짧은 점프와 긴 점프 |
| 수납장 밑 | 실제 구조물의 옆면에 붙기 → 오른쪽 이동 → 끝에서 점프로 이탈 |
| 싱크대 아래 | 물방울 예고와 바닥 표시를 읽고 받침으로 이동 |
| 식탁보 끝 | 병뚜껑 밀기 → 병뚜껑과 받침으로 두 번 점프 → 실밥 잡기 → 오른쪽으로 흔들다 이탈 |
| 마지막 문턱 | 일반 적 우회 또는 제압 → 쉼터 → 경비에 침 18회 명중 → 오른쪽 출구 통과 |

두 장은 조작·HUD·강화·저장 엔진을 공유한다. 기존 ant-adventure-save-v1 프로필의 chapter2 필드에 부엌 진행과 기록을 저장한다. 이전 초안의 별도 키는 유지하며 새 지형의 체크포인트로 자동 이전하지 않는다.

거실 보스는 14회 명중, 부엌 경비는 18회 명중이다. 경비는 더 빠른 돌진과 착지 지점을 미리 표시하는 내려찍기를 번갈아 쓰고, 착지 시 지면 충격파가 양쪽으로 퍼진다. 체력이 절반 이하가 되면 반격 시간이 짧아진다. 이전 검수판에서 누적한 명중 수와 경비 격파는 보존된다. 두 경우 모두 같은 미클리어 회차에서 재도전하면 잔여 체력이 유지된다. 부엌에서는 두 쉼터와 출구에서 설탕을 확정하며, 현재 검수판은 경비 처치 별도 보상 없이 맵 설탕만 지급한다.

검수 사이트와 로컬 미리보기의 첫 화면에서 챕터 바로 검수 버튼으로 거실·부엌을 선택할 수 있다. URL 매개변수 review=chapter1, review=climb, review=wet, review=kitchen, review=boss1, review=boss2을 이용해 해당 구간을 바로 열 수 있다. 각 바로가기는 별도의 검수용 저장을 쓰며 일반 캠페인에는 거실 해금 조건이 적용된다. 검수 사이트와 운영 사이트는 브라우저 저장을 각자 관리한다.

npm test로 두 장의 기본 능력 완주, 공유 강화, 저장·재도전, PWA 매니페스트와 캐시를 검증한다. 모바일 실기기에서는 화면 맞춤·멀티터치와 기존 설치본 업데이트를 확인한다.
