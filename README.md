# 개미의 모험 (Ant Adventure)

모바일 가로형 액션 보스 게임. **프로토타입** 단계입니다.

## 개발 현황 (2026-11-12)
- 기존 공개 프로토타입 및 PWA 적용은 이전 작업 이력에 기록되어 있으나, 현재 GitHub `main`에는 실행 소스가 확인되지 않습니다.
- 이 저장소의 소스·배포 일치 여부는 **미검증**입니다. 실행 파일을 확보하기 전에는 코드 수정·자동 테스트·재배포 완료로 간주하지 않습니다.

## 확정된 기획
- 주인공: 개미 / 보스: 베짱이(뚱뚱함, 평범함, 마름, 똑똑함 변형)
- 전투 중심, 주 공격: 침 뱉기
- 모바일 가로모드 전용. 이름 입력 중 가로형 키보드와 레이아웃 유지, 최초 진입 시 화면 맞춤
- 모바일 방향키 포함 조작 버튼 확대, 이동 버튼 반투명
- 재도전 시 보스 잔여 체력 유지 (체력 초기화 제거)
- 엔딩 5종: 평범한 부부 / 멱살 잡고 들어가는 개미 / 다리 끌고 들어가는 개미 / 개미 업고 들어가는 베짱이 / 현모양처 개미(희귀)
- 가루 오락실 대문에는 '프로토타입'으로 표기

## v0.2 개발 게이트
1. 실제 운영 중인 소스를 확보하고 GitHub에 백업(동기화). 운영 배포본을 덮어쓰지 않도록 별도 브랜치에서 시작합니다.
2. 모바일 가로모드 초기 화면·이름 입력·가로 키보드·리사이즈 회귀 테스트.
3. 공격 성공 횟수, 보스 체력과 피격 판정, 전투 난이도 계측 및 조정.
4. 버튼 크기 및 터치 영역 점검. 방향키 반투명 처리 후 가독성 검수.
5. 재도전 시 잔여 HP 유지와 신규 게임 시 HP 초기화의 구분 검증.
6. 엔딩 5종 조건 및 희귀 엔딩 도달 가능성 테스트.
7. PWA 단독 실행 / 가루 오락실 대문에서 진입 시 설치 및 홈 복귀 UI를 구분해 검수.
8. 테스트 통과 이후에만 운영 배포.

> 확인 전 상태는 '미확인' 또는 '미검증'으로 기록합니다.
