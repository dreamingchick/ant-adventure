# CHAPTER 02 — 부엌으로 가는 길 (플레이 가능한 초안)

## 범위
거실의 베짱이 대장을 처치한 뒤 진입하는 두 번째 지역입니다. 이 지역 명칭과 최종 지형·전투 수치는 **초안**이며, 사용자 실기기 검수 후 조정합니다.

## 연결
- 제1장 기존 저장 키 `ant-adventure-save-v1`의 `cleared=true`로 해금합니다.
- 제1장 클리어 화면과 첫 화면에 '제2장 · 부엌으로 가는 길' 버튼을 추가합니다.
- 제2장 페이지: `dist/stage2.html`.
- 제2장 저장 키: `ant-adventure-stage2-v1`. 제1장 프로필 및 강화·설탕 데이터를 수정하지 않습니다.

## 플레이
- 이동, 점프, 침 공격을 이용한 가로형 액션.
- 주방 수납장·식탁을 배경으로 발판과 위험한 과자 부스러기 구간을 이동합니다.
- 일반 베짱이 1종, 마른 베짱이 1종, 마지막 뚱뚱한 경비 베짱이를 배치합니다.
- 마지막 경비 베짱이 처치 후 출구에 도달하면 완료합니다.
- 체크포인트 3곳(시작 포함), 마지막 도달한 체크포인트부터 부활합니다.
- 피격 시 하트 감소. 사망 시 체크포인트 재도전.
- 클리어 기록(초 단위) 및 이미 처치한 베짱이의 상태를 저장합니다.
- 제3장은 구현되지 않았으므로 제2장 완료 이후 '추후 개방'으로 표시합니다.

## 기술적 제약 및 검수
- 최초 진입 화면 크기, 세로로 잡은 모바일의 가로 렌더링, 멀티터치, 배경과 전경 대비를 실기기 확인할 것.
- 시작 페이지에 남아 있는 저장 데이터의 호스트가 바뀌면 해금 상태가 공유되지 않을 수 있습니다.
- 플레이 중 적 공격 AI는 기본 추적과 접촉 피해이며 추가 패턴·연출은 후속 대상입니다.
- 제1장의 최종 결혼 엔딩 5종은 전체 여정 완성 시 도입하며 제2장 클리어로 출력하지 않습니다.
- 공개 사이트 배포는 별도의 검수 단계입니다.
