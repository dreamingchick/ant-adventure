# 개미의 모험 · 거실 대탈출

기획서 v0.2를 바탕으로 만든 브라우저 액션 프로토타입입니다. 주인공은 〈챠챠, 씻으러 가자〉의 밤색 개미이고, 베짱이 네 종류는 사용자 제공 디자인을 계승합니다.

## 실행

`dist/`를 정적 웹 서버로 제공하면 됩니다. 빌드·패키지 설치가 필요하지 않습니다.

```sh
python3 -m http.server 8080 --directory dist
```

브라우저에서 `http://localhost:8080`에 접속하세요. GitHub Pages나 다른 정적 호스팅에도 `dist` 내용을 배포할 수 있습니다. 현재 검수 사이트 설정은 `.openai/hosting.json`에 기록되어 있습니다.

## 조작

| 행동 | PC | 스마트폰 |
|---|---|---|
| 좌우 이동 | 방향키 또는 A/D | 왼쪽 방향 버튼 |
| 점프 | Space, 길게 누르면 높게 | 점프 버튼 |
| 침 공격 | Z, 누를 때마다 한 발 | 퉷! 버튼 |
| 벽 붙기·블록 밀기·실밥 잡기 | X | 상황별 버튼 |
| 일시정지 | Esc | 오른쪽 위 Ⅱ |

벽은 발자국 경로를 따라 좌우 키로 이동하고 점프로 이탈합니다. 실밥은 좌우 입력으로 흔들며 점프로 놓습니다. 부착·매달림 중에는 공격할 수 없습니다. 세로 방향에서는 게임 화면 전체를 가로 구도로 회전시켜 진행하며, 회전 안내로 멈추지 않습니다.

## 플레이 범위

- 거실 1개 스테이지: 소파 아래 → 탁자 다리 → 베짱이 길목 → 블록·실밥 → 챠챠 앞발 → 필수 전투 → 베짱이 대장.
- 높이 조절 점프, 벽·천장 이동, 미끄러운 선택 경로, 물건 밀기, 실밥 흔들기.
- 평범한·뚱뚱한·마른·똑똑한 베짱이, 대장 보스. 대장 체력 절반 이하에서 돌진 속도 증가.
- 침 게이지·자동 회복·피격 경직·하트·꿀방울·체크포인트.
- 설탕의 임시/확정 수집, 실패 복원, 최초 보스 보상 45개, 클리어 후 새 회차 일반 설탕 재배치.
- 클리어 준비 화면 전용 3항목 각 3단계 강화. 기본 비용 20/40/60개.
- 이름 변경, 개인 기록, 로컬 자동 저장, 이어 하기, 처음부터 재도전.
- 짧은 도입·보스 대화, 합성 배경음악과 효과음.

최종 결혼 엔딩 5종은 기획서에 정의되어 있으며, 이 거실 검수판에는 아직 구현하지 않았습니다. 후속 구역·배우자 관계 이벤트도 범위 밖입니다. 연속 스테이지 캠페인보다 기본 조작과 루프 검수가 목적입니다.

## 저장

저장 키는 `ant-adventure-save-v1`입니다. 같은 기기·브라우저·호스트에서 유지되며, 클리어·강화·체크포인트·이름 변경 시 저장됩니다. 브라우저 데이터 삭제나 비공개 모드에서는 보존되지 않을 수 있습니다. 저장 실패는 화면에 알립니다. 다른 게임의 저장 키는 변경하지 않습니다.

미클리어 상태에서 처음부터 다시 시작해도 확정 설탕을 중복 수집할 수 없습니다. 클리어 후 새 회차에서 일반 설탕을 재배치합니다. 보스 최초 보상과 강화 구매는 잔액과 함께 저장합니다.

재접속 시 경과 시간은 마지막 체크포인트 저장값부터 복원됩니다. 같은 실행 안에서는 사망·재도전 시간을 합산하지만, 마지막 저장 이후 종료까지의 시간은 별도로 보존하지 않습니다. 온라인 경쟁용 부정기록 방지는 범위 밖입니다.

## v0.1.2 — 실제 가로 키보드 입력

이름 입력을 터치하면 시스템 키보드를 열기 전에 전체 화면과 실제 `screen.orientation.lock('landscape')`를 요청합니다. 가로 고정에 성공한 뒤에만 이름 입력창을 활성화해 시스템 키보드를 엽니다. CSS로 화면만 회전시키는 처리와 구분합니다.

전체 화면/가로 고정이 없거나 거절·시간 초과되면 세로 시스템 키보드를 열지 않고 게임 내부 가로형 이름 키보드를 제공합니다. 한글 두벌식 조합(겹받침·복합 모음·쌍자음), 영문, 숫자, 공백, 지우기, 취소와 저장을 지원합니다. 처음 표시된 이름은 선택 상태로 시작하며 첫 입력으로 교체됩니다. 이름 길이는 12자로 제한합니다.

시스템 키보드 입력 중 전체 화면이 해제되거나 가로 고정이 풀려 세로로 돌아가면 현재 입력값을 유지해 내부 키보드로 전환합니다. 한글 조합과 가로 고정 성공·실패·지연·화면 입력 전환을 포함한 자동 테스트는 총 25개입니다. Android 실기기의 시스템 키보드 렌더링은 별도 기기 검수가 필요합니다.


## v0.1.3 — 스마트폰 조작 버튼 확대

좌우 이동은 80×76에서 132×124, 침 공격은 90×84에서 148×138, 점프는 102×100에서 160×160, 상황 버튼은 80×65에서 128×110으로 확대했습니다. 수치는 1280×720 게임 내부 좌표이며 실제 표시 크기는 화면 맞춤 비율에 따라 달라집니다. 일시정지 버튼과 스마트폰의 메뉴·대화 버튼도 확대했습니다.

이동 버튼은 배경 불투명도 30%, 누르는 동안 46%로 처리하고 배경 흐림을 제거해 아래 지형이 보이도록 했습니다. 아이콘은 선명하게 유지합니다. 모바일에는 불필요한 PC 키 안내를 숨겨 넓어진 버튼과 겹치지 않게 했습니다.

보스는 체력 14, 침 한 발 피해 1로 총 14회 명중해야 합니다. 7회 명중 후 돌진 속도가 증가하며, 사망 후 재도전해도 보스의 남은 체력을 유지합니다. 공격력 강화는 없습니다. 체력바 아래에 남은 명중 횟수를 표시합니다. 보스 명중 때마다 남은 체력을 저장해 사망·체크포인트 재도전·미클리어 상태의 처음부터 재도전·종료 후 이어 하기에도 유지합니다. 클리어한 뒤 새 회차를 시작할 때만 보스 체력이 14로 돌아옵니다.
